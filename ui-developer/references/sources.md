# Sources and further reference

Use this file when a task needs a standard, implementation pattern, or curated place to research examples. Do not load every source for ordinary UI work.

## Practical upstream

- [gabrielgreco1/skills — ui-humanizer](https://github.com/gabrielgreco1/skills/tree/main/ui-humanizer): informed the intent model, variation/motion/density calibration, reference-card workflow, explicit real-material inventory, rendered three-viewport review, and heuristic code scanning. Reviewed at commit `a3c2be7a844ffe8b0aa39c20f82dcbe776692757` (2026-11-02). Concepts were integrated and adapted to this skill's broader product and cross-platform workflow; the upstream files were not vendored wholesale.
- [Anthropic frontend-design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): subject-grounded direction, current generated-design clusters, two-pass plan and critique, and restrained signature decisions.
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines): detailed web implementation and review checks. Some copy and brand preferences are Vercel-specific; treat them as examples, not universal rules.

## Evidence about generated-UI patterns

- [HTTP Archive Web Almanac 2025 — Generative AI](https://almanac.httparchive.org/en/2025/generative-ai): useful counterweight to simplistic claims. Purple and gradients are recognizable discourse signals, but the dataset did not show a statistically significant surge for every claimed visual tell. Judge context and accumulation rather than a single color.
